# Snowflake Data Engineering Projects

A collection of hands-on projects built using Snowflake and SQL, covering
data warehousing, dimensional modelling, slowly changing dimensions,
semi-structured data, CDC, data security, governance, and advanced
analytical data modelling.

## Featured Projects

### 1. Enterprise Retail Analytics Data Warehouse
**Focus:** Data Warehousing, Kimball Methodology, Dimensional Modelling, SCD

Designed an enterprise-style retail analytics warehouse using fact and
dimension tables, dimensional modelling principles, and slowly changing
dimension strategies.

### 2. Healthcare Claims CDC Pipeline
**Focus:** Dynamic Tables, Streams, CDC, Semi-Structured Data

Built a healthcare claims pipeline using semi-structured JSON data,
CDC processing, Streams, Dynamic Tables, deduplication, and incremental
data processing.

### 3. Enterprise Customer MDM
**Focus:** Customer Data Management, SCD, Historical Data

Implemented customer master data management with historical tracking
and advanced SCD strategies.

### 4. Enterprise Data Security & Governance
**Focus:** RBAC, Dynamic Data Masking, Row Access Policies

Implemented Snowflake security and governance features for protecting
sensitive enterprise data and controlling access.

### 5. E-Commerce Fact Modelling
**Focus:** Transaction Facts, Snapshot Facts, Factless Facts

Implemented different dimensional modelling patterns including
transaction, periodic snapshot, accumulating snapshot, factless facts,
junk dimensions, and degenerate dimensions.

### 6. Logistics & Fleet Telematics Lakehouse
**Focus:** VARIANT, Semi-Structured Data, Medallion Architecture

Explored lakehouse architecture using semi-structured telematics data,
VARIANT, schema-on-read, and Snowflake Time Travel.
